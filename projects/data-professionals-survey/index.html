● PROJECT OVERVIEW

Using a publicly available survey dataset of 630 data professionals, I built an interactive Power BI dashboard that explores the realities of working in the data field — focusing on satisfaction levels, compensation trends, career entry experiences, and tool preferences.

All data cleaning and transformation was handled directly within Power BI using Power Query, including standardizing free-text responses, bucketing salary ranges, and handling nulls.

The dashboard was designed with both exploratory and communicative goals — guiding viewers from high-level satisfaction scores down to nuanced demographic breakdowns.
