● PROJECT OVERVIEW

Using a publicly available survey dataset of 630 data professionals, I built an interactive Power BI dashboard that explores the realities of working in the data field. The project focused on understanding satisfaction levels, compensation trends, career entry experiences, and tool preferences across the industry.

All data cleaning and transformation was handled directly within Power BI using Power Query. This included standardizing free-text responses, bucketing salary ranges, and handling nulls. The resulting model supported dynamic visuals that respond to slicer selections in real time.

The dashboard was designed with both exploratory and communicative goals in mind — the layout guides viewers through a story, from high-level satisfaction scores down to more nuanced demographic breakdowns that reveal where experiences differ most.

Salary satisfaction rated at approximately 5/10 — moderate dissatisfaction across respondents.

2

Work/life balance also rated around 5/10, indicating room for improvement industry-wide.

3

Entry difficulty into the data field rated as neutral overall, though nuances emerged across demographic groups.

4

Python emerged as the most preferred programming language among surveyed data professionals.

5

Data Scientists reported the highest average salary among all job titles in the survey.
