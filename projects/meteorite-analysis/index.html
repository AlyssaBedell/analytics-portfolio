● PROJECT OVERVIEW

This project used NASA's meteorite landings dataset to answer a specific question: where in the United States are meteorites most likely to be found? SQL was the right first step given the dataset's scale — I used it for cleaning and transformation before bringing the data into Tableau.

SQL cleaning involved removing nulls from key columns, filtering to U.S. landings only, and narrowing the time window to 1912–2012. This created a focused, analyzable dataset while preserving geographic diversity.

The Tableau dashboard features an interactive map where marker size represents mass, KPI cards summarizing total meteorites and average mass, and filters to toggle between 'found' and 'fell' classifications.

● SQL SAMPLE

SELECT

name, fall, year,

mass, reclat, reclong

FROM meteorite_landings

WHERE year BETWEEN 1912 AND 2012

AND reclong BETWEEN -125 AND -65

AND mass IS NOT NULL

ORDER BY mass DESC;

● KEY FINDINGS

1

Central U.S. — particularly Texas and surrounding states — emerged as the densest hotspot for recorded meteorite landings.

2

Heavier meteorites were significantly more likely to be recorded as 'falling' rather than 'found', suggesting larger impacts leave more recoverable remnants.

3

Filtering to U.S. landings from 1912–2012 reduced the dataset to a meaningful scope for geographic analysis.

4

The central U.S. concentration points to both geological conditions and population density as factors in meteorite recovery rates.
